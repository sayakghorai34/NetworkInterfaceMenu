# Contributing

Thanks for contributing.

## Local setup

```bash
git clone https://github.com/sayakghorai34/NetworkInterfaceMenu.git
cd NetworkInterfaceMenu
./build.sh
```

## Project expectations

- Keep the app as a menu-bar utility (`LSUIElement` behavior).
- Keep shell-facing inputs safely quoted.
- Avoid adding external dependencies unless there is a clear need.
- Update docs when behavior changes.
- Call out security-impacting changes in PRs.

## Pull request checklist

- Keep scope focused.
- Include validation steps and results.
- Mention macOS version tested.
- Keep UI/UX changes visible in screenshots when relevant.
- Wait for CI to pass before requesting final review.
